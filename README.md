# KigaliWetlandPulse

**KigaliWetlandPulse** is a lightweight, mobile-first digital visitor guide and trail interpretation prototype built for **Kigali Wetlands Park**.

Developed as part of the Bachelor of Technology in Tourism Management capstone project at **Rwanda Polytechnic (RP)**, the system supports sustainable, low-impact tourism through bilingual (English & Kinyarwanda) visitor information, QR-enabled trail stops, and planned audio interpretation—without requiring heavy physical structures or a native mobile app download.

## Repository Structure
- `index.html` — Main mobile visitor portal with hours, activities, facilities, park etiquette, language switcher, and trail stop links.
- `styles.css` — Mobile-responsive styling tailored for outdoor readability and low-impact web delivery.
- `stops/stop-1.html` — Trail Stop 1 interpretation page.
- `stops/stop-2.html` — Trail Stop 2 interpretation page.
- `stops/stop-3.html` — Trail Stop 3 interpretation page.
- `assets/audio/` — Planned `.mp3` narration files for each trail stop.
